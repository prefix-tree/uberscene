# @uberscene/codecs-darwin-x64

The `uberscene-codec` binary for macOS on Intel: UberScene's native codecs, built from
[`native/`](https://github.com/prefix-tree/uberscene/tree/main/native).

Don't install this package by name. Install [`@uberscene/codecs`](https://www.npmjs.com/package/@uberscene/codecs),
which brings the package for your platform.
