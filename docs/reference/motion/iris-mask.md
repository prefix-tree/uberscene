# Iris

The next shot opens out of a growing circle.

**What it conveys:** A new chapter, or a playful jump to the next scene.

## Use it when

- Chapter breaks and openers.
- A light, cartoon-like tone.

## Values

| | Value | |
|---|---|---|
| transition | `"iris", 0.8 s` | the next shot opens from a circle |

## Ask your agent

> Open the second shot from a circle with an 0.8 s iris transition.
