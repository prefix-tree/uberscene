# Shape Mask Transition

A circular mask expands from a point to reveal the next scene.

<Example src="previews/motion/iris-mask" alt="Shape Mask Transition">

<<< @/../examples/showcase/motion/iris-mask.tsx

</Example>

**What it conveys:** Shows new information spreading across the screen from a shared origin.

## Use it when

- Transition from a question to its answer.
- Open a detail scene from a selected point.

## Values

| | Value | |
|---|---|---|
| transition | `"iris", 0.8 s` | the next shot opens from a circle |

## Ask your agent

> Open the second shot from a circle with an 0.8 s iris transition.
