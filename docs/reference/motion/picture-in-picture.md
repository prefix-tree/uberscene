# Picture in picture

A small shot pops into a corner over the main one.

<Example src="previews/motion/picture-in-picture" alt="Picture in picture">

<<< @/../examples/showcase/motion/picture-in-picture.tsx

</Example>

**What it conveys:** Two views at once: a detail or a reaction alongside the main action.

## Use it when

- A reaction, a screen or a close-up that belongs with the main shot.
- A talking head over a demo.

## Values

| | Value | |
|---|---|---|
| box | `200 × 112, bottom right` | with 12 px rounded corners |
| scale | `0 to 1, easeOutBack` | the pop in |

## Ask your agent

> Pop a 200 × 112 inset into the bottom right corner with rounded corners and an easeOutBack scale.
