# Freeze with a label

The picture holds on one frame while a label names what is in it.

<Example src="previews/motion/freeze-frame-dressing" alt="Freeze with a label">

<<< @/../examples/showcase/motion/freeze-frame-dressing.tsx

</Example>

**What it conveys:** Stop and look: this is the thing.

## Use it when

- Introducing a person or a product in action.
- Pointing at one detail of a moving shot.

## Values

| | Value | |
|---|---|---|
| freezes | `{ start: 0.9, duration: 1.2, source: 18.9 }` | one held frame |
| label | `<Title>` | for the hold: starts and ends with the freeze |

## Ask your agent

> Hold one frame for 1.2 s with freezes, and show a label for exactly that time.
