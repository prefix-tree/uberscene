# Freeze Frame Dressing

Motion freezes on the beat and paper, tape, and labels stick around the frozen subject.

<Example src="previews/motion/freeze-frame-dressing" alt="Freeze Frame Dressing">

</Example>

**What it conveys:** A marker that says this moment matters: a magazine cover or documentary intro shot.

## Use it when

- Introduce a person or product for the first time.
- Make a decisive moment memorable.

## Values

| | Value | |
|---|---|---|
| freezes | `{ start: 0.9, duration: 1.2, source: 18.9 }` | one held frame |
| label | `a `&lt;Title>` for the hold` | starts and ends with the freeze |

## Ask your agent

> Hold one frame for 1.2 s with freezes, and show a label for exactly that time.
