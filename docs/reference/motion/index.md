# Motion catalog

Techniques of motion, each one short UberScene file in one look (paper, ink and one accent), so what differs is the motion alone. Hover a card to play it; each page has the file, the values it turns on and a prompt to give your agent. 27 techniques so far, most adapted from the 637 of [awesome-ai-motion](https://github.com/gongnyang/awesome-ai-motion) (MIT). Generated from `examples/showcase/motion-cards.ts` by `pnpm docs:gen`.
